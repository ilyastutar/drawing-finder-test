Drawing Finder v0.4 — OCR Benchmark

This version intentionally pauses feature development and compares the current Tesseract approach against PaddleOCR PP-OCRv5 on the same drawings and the same OCR zones.

Goal: measure recall before choosing the production OCR engine. PaddleOCR's browser SDK performs text detection + recognition and returns each line with coordinates and a confidence score; this benchmark keeps those results for later Related Tag/row clustering.
