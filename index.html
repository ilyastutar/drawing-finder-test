Project Folder Indexer

Folder mode: select one project folder and the app recursively walks every subfolder for PDFs. Automatic Table Detection is now the primary discovery method: every page is first rendered at low resolution, grid/table candidates are detected anywhere on the page, and only those table crops are sent to the existing high-resolution Google + Paddle OCR engine. Saved OCR zones are kept only as a fallback for pages where no table candidate is detected. Each completed PDF is checkpointed to IndexedDB, so a paused or interrupted project can continue without re-OCRing completed files. Keep this tab active for the fastest and most stable OCR run.
